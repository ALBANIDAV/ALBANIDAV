### 👨‍💻 Tentang Saya

Halo! Saya **Albani**, seorang **Software Engineer** yang gemar mengubah ide dan permasalahan kompleks menjadi solusi digital yang fungsional. Saya menikmati proses *end-to-end* dalam pengembangan perangkat lunak—mulai dari merancang antarmuka pengguna, membangun logika *backend*, hingga mengoptimalkan alur kerja dengan otomatisasi.

- 🛠️ **Fokus Pengembangan:** Web Application, API Development, & Software Architecture.
- 🌱 **Prinsip Kerja:** Menulis *clean code* yang mudah dipelihara (*maintainable*) dan terdokumentasi dengan baik.
- 🤝 **Kolaborasi:** Terbuka untuk berkontribusi pada proyek *open-source* dan eksplorasi ide baru.
- ⚡ **Habit:** *Debugging* sambil mengeksplorasi *tools* baru yang mempercepat produktivitas.
